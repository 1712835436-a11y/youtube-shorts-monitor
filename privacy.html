Privacy Policy

Last updated: October 2026

Overview

Shorts Monitor Analytics is a locally operated internal analytics application that uses YouTube Data API v3 to read public YouTube data for monitoring and analysis.

Data collected

The application may store public YouTube channel metadata, public video metadata, and public video statistics such as views, likes, and comment counts. It also stores periodic snapshots of these public statistics to calculate trends over time.

Private user data

The application does not use OAuth to access private YouTube user data and does not collect YouTube passwords or private account content.

How data is used

Collected public data is used only for internal monitoring, trend analysis, alerts, rankings, and reporting.

Data sharing

The application is currently operated locally for internal use and does not sell public YouTube data or personal user data to third parties.

YouTube content actions

The application does not upload, modify, delete, like, comment on, or otherwise change YouTube content.

Data retention and deletion

Public YouTube API data is retained only as needed for internal trend analysis and reporting. Stored data may be deleted when it is no longer required for the stated purpose.

Google Privacy Policy

This application uses YouTube Data API v3. Please also review the Google Privacy Policy.
