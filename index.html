YouTube Shorts Monitor

A locally operated internal analytics tool for monitoring selected public YouTube channels, public videos, and public video statistics using YouTube Data API v3.

Internal analytics · Read-only YouTube API usage

Project purpose

YouTube Shorts Monitor helps the operator monitor a configured list of YouTube channels and analyze changes in public video performance over time.

Channel monitoringTracks configured public YouTube channels and their public metadata.
Video monitoringReads recently published public videos from monitored channels.
Public statisticsStores snapshots of public statistics such as views, likes, and comment counts for trend analysis.
Internal reportingGenerates growth rankings, trend charts, alerts, and internal Excel reports.

YouTube API usage

The application uses YouTube Data API v3 with an API key to read public data required for monitoring and analysis.

  • Public channel metadata and uploads playlist information
  • Public video metadata
  • Public video statistics such as view, like, and comment counts

The application is read-only with respect to YouTube content.

It does not upload, edit, delete, like, comment on, or otherwise modify YouTube content. It does not use OAuth to access private YouTube user data.

Data handling

The application stores public YouTube channel/video metadata and periodic public-statistics snapshots in a private database for internal trend analysis. The application is currently operated locally and is not offered as a public consumer service.

No passwords, private YouTube account data, or private user content are collected by this application.

YouTube Shorts Monitor 是一个在本地运行的内部 YouTube 公开数据监控工具。它通过 YouTube Data API v3 读取已配置频道的公开频道信息、公开视频信息和公开视频统计数据，用于生成播放量趋势、增长榜、提醒和内部报表。
